# SCA Domain Glossary

## Professional
The central identity that evolves through learning, projects, skills, evidence and goals.

---

## FullName
An immutable Value Object representing a validated professional name.

---

## GoalTitle
An immutable Value Object representing the title of a professional goal.

---

## GoalStatus
Defines the lifecycle of a goal.

Values:
- NOT_STARTED
- IN_PROGRESS
- COMPLETED
